# 地图标注 · 活动行程工具（Map Annotation & Itinerary Tool）

一个**单文件、开箱即用**的 Web 地图工具，面向两类场景：

1. **标注模式** —— 在地图上自主标注地点、路线与几何图形（圆形、正方形、平行四边形、任意四边形、多边形），支持放大缩小、样式编辑、数据导入导出。
2. **行程模式** —— 面向活动嘉宾，管理「人员类别 → 点位 / 路线 → 行程安排」，按类别清晰展示**什么类别的人、什么时间、在哪个点位、走哪条路线**，并用 GPS / 北斗显示当前位置。

并支持将数据写入 **飞书多维表格**（可增删改查、双向导入导出）。

> 本项目为**发布版**：内嵌的高德 / 腾讯 API Key 已置为占位符（`YOUR_AMAP_KEY` / `YOUR_TENCENT_KEY`），使用前请按下文「配置说明」填入你自己的 Key。
> 全程原生 HTML/CSS/JS + Leaflet，无构建步骤，下载后双击即可在浏览器打开（建议 Chrome / Edge）。

## 功能特性

### 标注模式
- 支持图形：**地点（Marker）**、**路线（Polyline）**、**圆形**、**正方形**、**平行四边形**、**任意四边形**、**多边形**。
- 图形可**放大、缩小、拖动**；可选地点样式（图标 / Logo）、线型（实线 / 虚线）、线宽、颜色、填充色与透明度。
- 标注**可编辑名称、样式、位置**，可删除、可撤销。
- 路线支持两种方式：**手动标注**（逐个点点击绘制）与**开放服务自动规划**（点选起终点后调用高德 / 腾讯返回真实路径）。
- **导入 / 导出**标注数据（JSON）。

### 行程模式
- **人员类别**：可新增、编辑、删除类别，每类可填可选详情。
- **点位**：活动地点，可设到达时间、适用类别、备注。
- **路线**：连接点位的移动路线（默认调用高德驾车 API 的**推荐方案一**真实路径，非直线），可切换方案。
- **行程安排**：按时间轴展示，自动按**天分组**，每条含时段、标题、点位 / 路线、备注、人员类别与状态。
- **我的位置**：一键按钮，通过浏览器 GPS / 北斗（`navigator.geolocation`）定位真实位置（点击取一次，避免反复弹权限）。
- **导入 / 导出**行程数据（JSON）。

### 飞书云文档同步
- 顶栏「飞书」按钮打开**同步面板**：一键打开关联的飞书多维表格，在飞书里直接**查看 / 编辑 / 删除**每一行。
- **导出为飞书 JSON**：把当前页面数据（人员、点位、路线、行程、区域、标注）转为飞书多维表格格式 JSON 下载。
- **从飞书 JSON 导入**：读取飞书导出的 JSON，自动恢复本页数据。

## 使用方法

1. 双击 `地图标注工具.html` 在浏览器打开（建议 Chrome / Edge）。
2. 顶部可切换 **标注模式 / 行程模式**。
3. 标注模式：选左侧工具（地点 / 路线 / 圆形……）→ 在地图上点击绘制 → 右侧图层列表可编辑样式、重命名、删除。
4. 行程模式：先在「人员类别 / 点位 / 路线」里建好基础数据 → 到「行程安排」添加排期 → 用「我的位置」确认当前所在。
5. 点击顶栏「飞书」：打开多维表格在飞书里增删改，或用「导出 / 导入 JSON」与页面双向同步。

```js

  points:[{id,name,latlng,time,cats,note}],

  stops:[{id,title,start,end,kind:'point'|'route',ref,cats,note}],

{ 名称, 类型, 标识ID, 数据JSON, 备注 }
```

## 安全提示

- 请勿在**公开仓库**中提交真实 API Key（本发布版已占位）。Key 仅在本机 HTML / 浏览器本地使用。
- 飞书多维表格 token 属于资源标识，公开仓库中暴露后，未获你分享的他人仍无法访问（需在飞书内授权）；如需完全保密可自行更换表或改为私有仓库。
- 地图瓦片与路线接口均为第三方服务，实际可用性以服务商为准。
