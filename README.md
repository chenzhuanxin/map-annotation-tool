# 地图标注 · 活动行程工具（Map Annotation & Itinerary Tool）

一个**单文件、离线可开箱**的 Web 地图工具，面向两类场景：

1. **标注模式** —— 在地图上自主标注地点、路线与几何图形（圆形、正方形、平行四边形、任意四边形、多边形），支持放大缩小、样式编辑、数据导入导出。
2. **行程模式** —— 面向活动嘉宾，管理「人员类别 → 点位 / 路线 → 行程安排」，按类别清晰展示**什么类别的人、什么时间、在哪个点位、走哪条路线**，并用 GPS / 北斗显示当前位置。

> 本项目为**发布版**：内嵌的高德 / 腾讯 API Key 已置为占位符（`YOUR_AMAP_KEY` / `YOUR_TENCENT_KEY`），使用前请按下文「配置说明」填入你自己的 Key。
> 全程使用原生 HTML/CSS/JS + Leaflet，无构建步骤，下载后双击即可在浏览器打开（建议 Chrome / Edge）。

## 功能特性

### 标注模式（`地图标注工具.html`）
- 支持图形：**地点（Marker）**、**路线（Polyline）**、**圆形**、**正方形**、**平行四边形**、**任意四边形**、**多边形**。
- 图形可**放大、缩小、拖动**；可选地点样式（图标 / Logo）、线型（实线 / 虚线等）、线宽、颜色、填充色与透明度。
- 标注**可编辑名称、样式、位置**，可删除、可撤销。
- 路线支持两种方式：
  - **手动标注**：逐个点点击绘制。
  - **开放服务自动规划**：点选起点 / 终点后，调用**高德 / 腾讯**路线 API，返回真实路径并作为标注路线。
- **导入 / 导出**标注数据（JSON），可离线保存与恢复。

### 行程模式
- **人员类别**：可新增、编辑、删除类别，每个类别可填可选详情（嘉宾 / 演艺人员 / 工作人员……）。
- **点位**：活动地点（机场、客运站、酒店、景区……），可设到达时间、适用类别、备注。
- **路线**：连接点位之间的移动路线（默认调用高德驾车 API 的**推荐方案一**真实路径，非直线），可切换 / 选择方案。
- **行程安排**：按时间轴展示，自动按**天分组**（如「10月30日 · 周五」），每条含时段、标题、点位 / 路线、备注、人员类别与状态，跨天自动标注。
- **我的位置**：一键按钮，通过浏览器 GPS / 北斗（`navigator.geolocation`）定位真实位置并在地图上显示（手机端即手机当前位置）。
- **导入 / 导出**行程数据（JSON）。

1. 申请地图开放平台 Key（免费）：
   - **高德开放平台**：https://console.amap.com/ （「Web服务」应用，勾选地理编码、关键字搜索、路径规划服务）。
   - **腾讯位置服务**：https://lbs.qq.com/ （需开通「驾车路线规划」等服务）。

## 使用方法

1. 双击 `地图标注工具.html` 在浏览器打开（首次建议用 Chrome / Edge）。
2. 顶部可切换 **标注模式 / 行程模式**。
3. 标注模式：选左侧工具（地点 / 路线 / 圆形……）→ 在地图上点击绘制 → 右侧图层列表可编辑样式、重命名、删除。
4. 行程模式：先在「人员类别 / 点位 / 路线」里建好基础数据 → 到「行程安排」添加排期 → 用「我的位置」确认自己当前所在。
5. 任意时刻用右上角「导出」保存为 JSON，「导入」恢复。

## 数据模型（导入 / 导出 JSON）

```js
// 标注 feature
{ id, type:'marker'|'route'|'circle'|'square'|'parallel'|'quad'|'polygon',
  label, color, weight, dash, fillColor, fillOpacity, icon,
  latlng | center+radius | latlngs }

// 行程 app
{ name, date, cats:[{id,name,color,detail}],
  points:[{id,name,latlng,time,cats,note}],
  routes:[{id,name,latlngs,cats,color,weight,dash,note}],
  stops:[{id,title,start,end,kind:'point'|'route',ref,cats,note}],
  zones:[{id,kind,...}] }
```
